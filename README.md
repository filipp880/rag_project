# Multi-Step RAG Agent

Проект по созданию RAG-агента с гибридным поиском и вызовом инструментов (Tool Calling).

## Структура проекта
* `data/` — директория для текстовых документов и баз знаний.
* `ingest.py` — скрипт загрузки, чанкинга с перекрытием (overlap) и индексации в ChromaDB.
* `agent.py` — логика работы агента, фильтрация метаданных и цикл вызова инструментов (Tool Routing).

## Известные ограничения (Known Limitations)
* **Планирование 3B-моделей (llama3.2):** Небольшие локальные модели могут вызывать итоговые инструменты с некорректными/выдуманными параметрами вместо последовательного выполнения всей цепочки вызовов (например, прямого вызова `calculate` вместо последовательности `get_weather` ➔ `calculate`).
* **Точки роста:** Использование более крупной модели (от 8B параметров и выше) или явная декомпозиция сложных запросов перед передачей агенту.
